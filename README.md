# Chorus Logo Motion

Animated Chorus Health logo: the eight strings of the symbol move as a travelling sine wave, with the inner shapes riding, stretching and trailing along their lines.

**Live page:** https://hankwhiteco.github.io/chorus-logo-motion/ — tune the motion, preview it, and export it.

## Behaviour

1. **Intro** — strings grow out from their centres, inner shapes grow open.
2. **Intro wave** — the wave plays briefly, then settles back to the exact original logo.
3. **Hover** — the wave eases back in while hovered and settles when the pointer leaves.

Respects `prefers-reduced-motion` (shows the static logo) and stops animating entirely when at rest.

## Files

| File | What it is |
|---|---|
| `ChorusLogoMotion.tsx` | Framer code component (Brown `#453830`). Every setting is a property control. |
| `ChorusLogoMotionLight.tsx` | Same component in Cream (`#FBF5EE`) — generated by `build.cjs`, don't edit directly. |
| `index.html` | The live controls page — generated by `build.cjs`. |
| `logo-export.js` | Export tool used by the page: GIF, MP4, and a standalone React component. |
| `build.cjs` | Rebuilds `index.html` and `ChorusLogoMotionLight.tsx` from `ChorusLogoMotion.tsx`. |
| `assets/` | Wordmark and nav lockup (262 × 37) artwork. |

## Using it

- **Framer:** Assets → Code → new code file, paste `ChorusLogoMotion.tsx`, drag it onto the page. With **Wordmark** on it lays out the 262 × 37 nav lockup, and hovering anywhere on it triggers the wave.
- **React / Next.js:** on the live page choose *Export → React component (.tsx or .jsx)*. You get a standalone component with your current settings as defaults: `<ChorusLogoMotion style={{ height: 37 }} />`.
- **GIF / MP4:** *Export* on the live page — full logo or symbol only, seamless loop or intro only, transparent background (GIF).

## Editing

Edit `ChorusLogoMotion.tsx` (or `logo-export.js`), then:

```bash
node build.cjs
```

To preview locally, serve the folder (WebCodecs MP4 export needs `http://localhost` or HTTPS):

```bash
python3 -m http.server 8161
```
